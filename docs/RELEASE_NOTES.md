# 카카오톡 톡클라우드 정리 v1.0.0-rc.2

사진·GIF·동영상을 목록에서 바로 구분할 수 있도록 썸네일을 추가한 **정식 1.0 출시 전 후보 버전**입니다. 실제 계정 통합 검증은 아직 완료되지 않았습니다.

## 변경 사항

- **목록에서 바로 확인:** 사진·GIF는 썸네일을, 동영상은 대표 이미지와 동영상 배지를 표시합니다. **썸네일 칸**을 누르면 확대합니다. 동영상은 자동 재생하지 않으며 GIF 썸네일의 애니메이션 재생은 보장하지 않습니다.
- **필요한 이미지만 불러오기:** 목록 응답의 썸네일 주소를 검증해 사용하며, 주소를 얻기 위한 개별 상세 조회 없이 현재 페이지에서 화면에 가까워진 이미지를 불러옵니다. 원본 파일을 자동으로 저장하지 않습니다.
- **이름과 이미지가 없을 때:** 파일명이 없으면 종류와 날짜를 대신 표시합니다. 썸네일이 없거나 이미지 요청이 실패하면 자리표시를 보여 주며, **썸네일 칸**을 누르면 상세 정보를 다시 확인할 수 있습니다.
- **썸네일 주소 비저장:** 썸네일 주소는 관리 화면의 메모리에서만 사용하고, 계정별 작업 기록이나 내보낸 JSON에 포함하지 않습니다. 기존 확장 권한을 유지합니다.
- **짧은 사용 안내:** 설치와 정리를 각각 세 단계로 안내하고, 보호·업데이트 등 세부 내용은 필요할 때 펼쳐 볼 수 있습니다.

## 1.0 후보 버전에 포함된 기능

- **작업 이어가기:** 계정별 조회 조건·선택 정보·다운로드 확인 기록과 최근 두 작업의 결과를 로컬에 보관합니다. 마지막 저장 후 7일 이내 기록이 대상입니다.
- **복원 전 재확인:** 현재 계정과 최신 목록을 조회하고 정보가 같은 항목만 다시 선택합니다. 다운로드 완료 기록도 브라우저에서 재검증합니다. 삭제는 자동으로 재개하지 않습니다.
- **처리 결과 안내:** 완료 확인·요청됨/확인 필요·아직 시작하지 않음을 구분합니다. 결과 재확인 버튼은 남은 항목을 다시 선택하며, 실제 실행은 별도 확인을 거칩니다.
- **첫 사용과 오류 안내:** 세 단계 사용 안내와 업데이트 설명을 제공하고 로그인·인증·오래된 목록·닫힌 원본 탭에 필요한 다음 행동을 안내합니다.
- **중복 관리 탭 방지:** 같은 톡클라우드 탭에서 확장 아이콘을 다시 누르면 기존 관리 화면으로 돌아갑니다.
- 계정별 보호 목록의 저장 키와 MIT 라이선스를 유지합니다. 작업 기록 지우기는 보호 목록과 PC에 저장한 파일을 지우지 않습니다.

작업 기록에는 파일명·식별자·결과 등이 포함되므로 공개하지 마세요. 원본 URL·로그인 정보·PC 절대 경로는 기록하지 않습니다. 7일은 복원 유효기간이며 저장 데이터의 디스크 자동 삭제를 뜻하지 않습니다. 자세한 내용은 [개인정보 처리 안내](PRIVACY.md)를 확인하세요.

## 설치 및 업데이트

실행용 ZIP을 압축 해제한 뒤 Edge의 `edge://extensions`에서 **개발자 모드 → 압축 풀린 확장 로드**로 `manifest.json`이 있는 폴더를 선택하세요. 소스 코드 ZIP을 받았다면 그 안의 `extension` 폴더를 선택합니다.

기존 사용자는 실행 중인 작업이 끝난 뒤 기존 파일을 별도로 보관하고 새 파일을 같은 설치 폴더에 반영합니다. 확장을 **다시 로드**한 뒤 관리 탭을 새로 열어 **1.0.0-rc.2**를 확인하세요. 같은 설치본의 기존 보호 설정은 유지합니다.

설치 폴더·프로필을 바꿀 경우 기존 확장의 **보호 설정 이전**에서 백업하고 새 설치본에 복원하세요. 복원 확인 전까지 기존 확장은 유지합니다. 보호 설정 이전에는 작업 이어가기 기록이 포함되지 않습니다.

## 사용 전 확인

카카오 공식 프로그램이 아니며 내부 요청 방식 변경에 영향을 받습니다. 자동 테스트는 실제 서비스 통합 검증을 대신하지 않습니다. 정식 1.0 출시 전 소량 항목으로 조회·다운로드·휴지통 이동·보호 제외·오류 후 복구·탭 복원·기존 버전 업데이트를 확인해야 합니다. 영구 삭제 기능은 제공하지 않습니다.

사진·GIF·동영상·일반 첨부 파일의 PC 저장을 지원합니다. 보이스톡 통화녹음과 링크는 다운로드하지 않으며 팀·드라이브 데이터는 지원하지 않습니다. 자세한 사용법과 개인정보 처리 범위는 저장소의 README와 개인정보 처리 안내를 확인하세요.
