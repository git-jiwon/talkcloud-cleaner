# 카카오톡 톡클라우드 정리 v1.0.0

오래된 사진·동영상·파일을 찾아 직접 고르고 휴지통으로 옮기는 Edge 확장입니다. PC 저장은 선택입니다.

## 주요 기능

- 날짜·유형·크기로 찾기, 큰 파일 보기, 열 정렬과 채팅방별 목록
- 사진·GIF 썸네일과 동영상 대표 이미지, 클릭 확대
- 선택 파일 PC 저장, 개별 항목·채팅방·중요 표시 보호
- 남은 목록 유지, 중단한 작업 이어가기와 처리 결과 확인

## 이번 수정

- 목록 위에서 **전체 선택**과 **현재 페이지 선택**을 바로 사용할 수 있습니다. 전체 선택은 현재 검색·필터 결과를 다른 페이지까지 포함합니다.
- 중요 표시 보호를 바꿔도 나머지 조회 목록과 선택을 유지합니다. 보호를 켜면 해당 대상만 제외합니다.

## 설치·업데이트

1. 설치용 ZIP을 받아 계속 보관할 폴더에 압축을 풉니다.
2. Edge의 `edge://extensions` → **개발자 모드 → 압축 풀린 확장 로드**에서 `manifest.json`이 있는 폴더를 고릅니다. 소스 ZIP은 `extension` 폴더입니다.
3. 톡클라우드에 로그인하고 확장 아이콘을 누릅니다.

기존 사용자는 파일을 별도 보관한 뒤 최신 ZIP을 같은 설치 폴더에 반영하고 **다시 로드**하세요. 관리 탭을 새로 열어 목록 위의 **전체 선택** 버튼을 확인합니다. 같은 Edge 프로필·설치본의 보호 설정은 유지됩니다. 폴더·프로필 변경 시에는 **보호 설정 이전**으로 백업·복원하세요.

카카오의 비공식 도구이며 영구 삭제는 하지 않습니다. 실제 파일명·채팅방·목록 JSON과 보호 백업은 공개하지 마세요.
