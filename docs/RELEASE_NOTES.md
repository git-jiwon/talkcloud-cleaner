# 카카오톡 톡클라우드 정리 v1.0.0

날짜·유형·크기로 오래된 항목을 찾고, 썸네일로 확인한 뒤 직접 골라 정리하는 Edge 확장 프로그램입니다. PC 저장은 선택입니다.

## 1.0 주요 기능

- **찾고 고르기:** 날짜·유형·크기 조건, 큰 파일 보기, 열 정렬, 채팅방별 목록
- **목록 미리보기:** 사진·GIF 썸네일과 동영상 대표 이미지, 클릭 확대, 이름 없는 사진의 종류·날짜 표시
- **휴지통 정리:** 저장 없이 이동, 처리 후 남은 목록 유지, 개별 항목·채팅방·중요 표시 보호
- **필요한 파일 보관:** 사진·GIF·동영상·일반 파일을 PC에 저장하고 완료 기록 확인
- **작업 이어가기:** 계정별 조건·선택·다운로드 기록과 최근 두 작업의 결과 확인, 최신 목록으로 재확인 후 수동 실행
- **짧은 사용 안내:** 설치·정리 각 세 단계, 보호·업데이트 등 상세는 펼쳐 보기

동영상은 대표 이미지만 표시하며 GIF는 움직이지 않을 수 있습니다. 보이스톡 통화녹음·링크는 PC 저장을, 팀·드라이브 데이터는 조회·정리를 지원하지 않습니다.

## 설치·업데이트

1. 실행용 ZIP을 받아 계속 보관할 폴더에 압축을 풉니다.
2. Edge의 `edge://extensions`에서 **개발자 모드 → 압축 풀린 확장 로드**를 누르고 `manifest.json`이 있는 폴더를 고릅니다. 소스 ZIP은 `extension` 폴더입니다.
3. 공식 톡클라우드에 로그인하고 확장 아이콘을 누릅니다.

업데이트는 작업을 끝내고 기존 파일을 별도 보관한 뒤 새 파일을 같은 설치 폴더에 반영합니다. 확장을 **다시 로드**하고 관리 탭을 새로 열어 **1.0.0**을 확인하세요. 같은 설치본의 보호 설정은 유지합니다. 폴더·프로필을 바꾼다면 **보호 설정 이전**으로 백업·복원하세요.

## 확인 범위

자동 테스트 378개와 공개 파일 45개 검사를 통과했습니다. 실제 계정 통합 검증은 아직 완료되지 않았습니다. 처음에는 소수의 항목으로 조회·저장·휴지통 이동을 확인하세요.

카카오의 비공식 도구이며 서비스 변경에 영향을 받을 수 있습니다. 영구 삭제는 하지 않습니다. 작업 기록·JSON에는 파일명과 식별자가 포함될 수 있으므로 공개하지 마세요. 원본·썸네일 URL, 로그인 정보와 PC 절대 경로는 작업 기록에 저장하지 않습니다.
