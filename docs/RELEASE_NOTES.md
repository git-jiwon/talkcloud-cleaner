# 톡클라우드 정리 v0.7.2

설치·사용 안내를 현재 화면에 맞게 정리하고 공개 배포 문서를 추가한 버전입니다.

## 변경 사항

- 개인 작업 경로와 특정 설치본에 종속된 안내를 제거했습니다.
- 실행용 ZIP과 소스 코드 ZIP의 설치 폴더를 구분했습니다.
- 저장 없이 정리하는 세 단계 흐름과 선택 다운로드를 설명했습니다.
- 처리 후 남은 목록 유지, 오류·중지 후 재조회, 화면 밖 선택과 50 MB 필터 동작을 안내했습니다.
- 보호 설정 백업·복원을 모든 사용자에게 적용할 수 있는 절차로 정리했습니다.
- README와 개인정보 처리 안내를 추가했습니다.
- 다운로드 결과 JSON에서 PC의 전체 저장 경로를 제외하고, 선택 목록 JSON에서 선택하지 않은 보호 항목의 식별자를 제외했습니다.
- 원본 오류 메시지가 내보내기 기록에 그대로 포함되지 않도록 제한했습니다. 파일 이름·선택 항목 식별자 등 기록에 필요한 정보는 남으므로 JSON은 비공개로 보관하세요.
- 허용한 파일만 검사·패키징하는 도구를 추가해 개인 작업 기록과 참고 소스가 공개 ZIP에 섞이지 않도록 했습니다.

## 설치 및 업데이트

실행용 ZIP을 압축 해제한 뒤 Edge의 `edge://extensions`에서 **개발자 모드 → 압축 풀린 확장 로드**로 `manifest.json`이 있는 폴더를 선택하세요. 소스 코드 ZIP을 받았다면 그 안의 `extension` 폴더를 선택합니다.

기존 사용자는 설치 파일을 업데이트하고 확장을 **다시 로드**한 뒤 관리 탭을 새로 여세요. 설치 폴더·프로필을 바꿀 경우 기존 확장의 **보호 설정 이전**에서 백업하고 새 설치본에 복원하세요. 복원 확인 전까지 기존 확장은 유지합니다.

## 사용 전 확인

카카오 공식 프로그램이 아니며 내부 요청 방식 변경에 영향을 받습니다. 자동 테스트와 가상 데이터 화면으로 검증했지만 실제 계정의 전체 통합 검증은 완료되지 않았습니다. 영구 삭제 기능은 제공하지 않습니다.

사진·GIF·동영상·일반 첨부 파일의 PC 저장을 지원합니다. 보이스톡 통화녹음과 링크는 다운로드하지 않으며 팀·드라이브 데이터는 지원하지 않습니다. 자세한 사용법과 개인정보 처리 범위는 저장소의 README와 개인정보 처리 안내를 확인하세요.
