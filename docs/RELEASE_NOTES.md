# 카카오톡 톡클라우드 정리 v0.7.4

노란 구름·체크 아이콘을 추가하고, 프로그램과 GitHub 소개에서 카카오톡 톡클라우드 정리 도구임을 명확하게 표시했습니다. 코드 재검토에서 발견한 조회 유효기간 검사 누락도 수정했습니다.

## 변경 사항

- Edge 툴바·확장 목록·관리 탭에 노란 아이콘을 적용했습니다.
- 프로그램 이름과 README 제목을 **카카오톡 톡클라우드 정리**로 통일했습니다. 카카오의 공식 프로그램은 아닙니다.
- 삭제 확인창을 오래 열어 두거나 대량 처리 도중 조회 후 1시간이 지나면 다음 삭제 요청을 보내지 않고 재조회를 안내합니다.
- 긴 이모지 파일명이 Windows 파일명 길이 제한을 넘지 않도록 수정했습니다. 문자와 확장자는 보존합니다.
- 아이콘은 개인정보 메타데이터 없이 직접 생성하며, 검사한 아이콘만 설치 ZIP과 소스 ZIP에 포함합니다.
- 기존 보호 설정의 저장 방식과 MIT 라이선스는 유지합니다.

코드 재검토에서는 삭제 조건, 다운로드 결과 확인, 보호 설정 복원과 목록 정렬을 모의 데이터로 확인했습니다. 브라우저 다운로드 기록의 파일 존재 정보는 갱신이 늦을 수 있으므로 보관 파일은 직접 열어 확인하세요.

## 설치 및 업데이트

실행용 ZIP을 압축 해제한 뒤 Edge의 `edge://extensions`에서 **개발자 모드 → 압축 풀린 확장 로드**로 `manifest.json`이 있는 폴더를 선택하세요. 소스 코드 ZIP을 받았다면 그 안의 `extension` 폴더를 선택합니다.

기존 사용자는 설치 파일을 업데이트하고 확장을 **다시 로드**한 뒤 관리 탭을 새로 여세요. 설치 폴더·프로필을 바꿀 경우 기존 확장의 **보호 설정 이전**에서 백업하고 새 설치본에 복원하세요. 복원 확인 전까지 기존 확장은 유지합니다.

## 사용 전 확인

카카오 공식 프로그램이 아니며 내부 요청 방식 변경에 영향을 받습니다. 자동 테스트와 가상 데이터 화면으로 검증했지만 실제 계정의 전체 통합 검증은 완료되지 않았습니다. 영구 삭제 기능은 제공하지 않습니다.

사진·GIF·동영상·일반 첨부 파일의 PC 저장을 지원합니다. 보이스톡 통화녹음과 링크는 다운로드하지 않으며 팀·드라이브 데이터는 지원하지 않습니다. 자세한 사용법과 개인정보 처리 범위는 저장소의 README와 개인정보 처리 안내를 확인하세요.
