# 개인정보와 권한

카카오톡 톡클라우드 정리는 사용자가 로그인한 톡클라우드에서 항목을 조회하고, 선택한 항목을 휴지통으로 옮기는 브라우저 확장입니다. 별도 개발자 서버, 광고, 사용 통계 전송 기능은 없습니다. 기능 수행에 필요한 정보는 카카오 서비스, 현재 브라우저와 사용자가 저장한 파일에서 처리됩니다.

## 네트워크 요청

- 원래 톡클라우드 탭의 로그인 세션으로 카카오 API에 계정 확인, 목록 조회, 파일 정보 조회와 휴지통 이동을 요청합니다. 요청에는 브라우저가 해당 서비스에 적용하는 인증 정보가 포함될 수 있습니다.
- 확장은 비밀번호나 쿠키 문자열을 직접 읽거나 설정 백업에 저장하지 않습니다. 로그인과 추가 인증은 공식 톡클라우드에서 진행합니다.
- 파일 저장을 선택하면 카카오가 제공한 파일 주소를 Edge 다운로드 기능에 전달합니다. 다운로드 주소에는 접근용 서명 정보가 포함될 수 있으며, 브라우저 다운로드 기록에 주소와 저장 경로가 남을 수 있습니다.
- 사진·GIF의 **미리보기**를 누르면 해당 항목을 다시 확인하고 카카오 서비스가 제공하는 썸네일을 불러옵니다. 주소는 허용된 카카오 HTTPS 호스트만 사용하며 작업 기록에 저장하지 않습니다. 썸네일 요청은 카카오 서비스에 전달되고 브라우저 캐시에 남을 수 있습니다.
- 확장은 외부 글꼴이나 분석 스크립트를 불러오지 않습니다. 사진은 사용자가 미리보기를 요청할 때 불러옵니다. 공식 서비스 링크를 누르면 해당 사이트의 정책이 적용됩니다.

## 브라우저와 파일에 남는 정보

| 위치 | 정보 | 유지 범위 |
| --- | --- | --- |
| 확장 프로그램의 localStorage: 보호 목록 | 카카오 계정의 해시 식별자, 보호 항목·채팅방의 ID와 이름 | 같은 브라우저 프로필과 확장 설치본에서 유지 |
| 확장 프로그램의 localStorage: 작업 기록 | 계정별 조회 조건, 검토 필터, 선택 항목의 ID·파일명·날짜·크기·채팅방 ID 등 비교 정보, 다운로드 ID·저장 파일명·크기, 최근 두 작업의 항목과 결과 | 마지막 저장 후 7일 이내 복원 대상. 사용자가 작업 기록을 지우거나 확장 데이터를 초기화할 때까지 저장 데이터가 남을 수 있음 |
| 확장 프로그램의 localStorage: 사용 안내 | 마지막으로 확인한 확장 버전 | 같은 브라우저 프로필과 확장 설치본에서 유지 |
| 열린 관리 화면의 메모리 | 조회 목록, 파일명·날짜·용량·채팅방 정보, 선택 항목, 작업 진행 상태, 다운로드 확인 기록과 현재 썸네일 주소 | 관리 화면을 닫으면 해당 화면의 메모리 상태 종료. 작업 이어가기에 필요한 일부 정보는 위 로컬 기록으로 유지 |
| Edge 다운로드 폴더와 기록 | 사용자가 저장한 원본 파일, 다운로드 URL·파일명·경로 등 | 브라우저와 사용자 관리에 따름 |
| 사용자가 내보낸 JSON | 아래 표에 기재한 정보 | 사용자가 파일을 보관하는 동안 유지 |

보호 설정을 변경해도 이미 저장한 JSON이나 다운로드 파일은 바뀌지 않습니다. 확장을 제거해도 PC에 저장한 파일과 브라우저 다운로드 기록은 별도로 남을 수 있습니다.

작업 기록에는 원본·미리보기 다운로드 URL, 비밀번호·쿠키 등 로그인 정보, PC의 절대 저장 경로와 실제 파일 내용을 저장하지 않습니다. 파일명은 경로를 뺀 이름만 보관합니다. 작업 기록과 JSON은 암호화된 보관함이 아니므로 같은 브라우저 프로필과 PC를 사용하는 사람의 접근도 고려하세요.

7일은 작업 이어가기의 유효기간이며, 기간이 지나면 저장 데이터가 디스크에서 자동으로 삭제된다는 뜻은 아닙니다. **작업 기록 지우기**는 현재 계정의 작업 기록을 지우며 보호 목록과 다운로드한 PC 파일에는 영향을 주지 않습니다. 저장 공간 부족이나 손상된 기록은 안내하고, 기록을 복원하지 못한 상태로 삭제를 자동 재개하지 않습니다.

## JSON 파일에 포함되는 정보

| 종류 | 포함하는 내용 | 포함하지 않는 내용 |
| --- | --- | --- |
| 목록 정보 | 조회 조건과 선택한 항목의 ID·파일명·채팅방 ID·날짜·용량·유형 | 계정 식별자, 선택하지 않은 보호 항목 목록, 다운로드 주소, 파일 본문 |
| 다운로드 결과 기록 | 실행 시각, 상대 백업 폴더, 항목 이름, 저장된 파일명, 크기와 결과 | PC 전체 저장 경로, 다운로드 URL, 로그인 정보, 파일 본문 |
| 전체 결과 기록 | 최근 두 작업의 유형·시작/종료 시각, 항목의 ID·파일명·유형·크기와 처리 상태 | 계정 식별자, 다운로드 URL, 로그인 정보, 파일 본문 |
| 보호 설정 백업 | 저장된 모든 보호 계정의 해시 식별자, 보호 파일·채팅방의 ID와 이름 | 비밀번호, 쿠키, 삭제 대상 선택, 파일 본문 |

이 JSON 파일은 암호화되지 않습니다. 해시 식별자도 계정을 구분할 수 있는 정보이며, 파일명과 채팅방 이름에는 개인정보가 포함될 수 있습니다. GitHub 이슈·저장소·공개 댓글에 원본 JSON이나 실제 목록 화면을 첨부하지 마세요. 오류를 공유할 때는 가상 이름과 식별자로 바꾼 재현 예시를 사용하세요.

## 확장 권한

| 권한 | 사용 목적 |
| --- | --- |
| `activeTab` | 사용자가 확장 아이콘을 누른 톡클라우드 탭에 연결 |
| `scripting` | 연결한 탭에서 조회와 휴지통 이동을 위한 코드를 실행 |
| `downloads` | 사용자가 선택한 파일 저장, 해당 다운로드의 완료 확인·중지, 다운로드 폴더 열기 |

전체 방문 기록이나 모든 사이트에 대한 상시 접근 권한을 선언하지 않습니다. `downloads`는 브라우저 차원에서 다운로드 기록에 접근 가능한 권한이지만, 현재 코드는 이 도구가 생성한 다운로드 ID의 상태를 확인하는 데 사용합니다.

## 설정 보관과 이전

보호 파일은 관리 화면의 보호 목록에서, 보호 채팅방은 채팅방 체크를 해제하여 변경할 수 있습니다. 설치 폴더나 브라우저 프로필을 바꿀 때는 기존 확장의 **보호 설정 이전**에서 백업을 만든 뒤 새 설치본에 합쳐 복원하세요. 복원한 항목 수를 확인할 때까지 기존 설치본을 유지하세요.

같은 설치 폴더에서 확장을 다시 로드하는 업데이트는 기존 계정별 보호 키를 유지합니다. 보호 설정 이전 파일에는 작업 조건·선택·다운로드 확인 기록·작업 결과가 들어 있지 않습니다. 작업 이어가기는 현재 로그인 계정과 최신 목록을 확인한 뒤 적용하며, 다운로드 완료 기록은 브라우저에서 다시 확인합니다.

이 안내는 1.0.0-rc.1 코드의 데이터 처리 방식을 설명합니다. 카카오와 Edge 자체의 데이터 처리에는 각 서비스의 정책이 적용됩니다.
