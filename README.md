# 카카오톡 톡클라우드 정리

<img src="extension/icons/icon128.png" width="64" height="64" alt="노란 구름과 체크 표시 아이콘">

톡클라우드의 오래된 항목을 날짜·유형·크기로 찾아 직접 선택하고 휴지통으로 옮기는 Edge 확장 프로그램입니다. 사진·동영상·문서의 PC 저장은 선택사항입니다.

**현재 버전: 0.7.4** · 카카오의 공식 프로그램이 아닙니다.

## 주요 기능

- 지정 날짜 이전 항목 조회와 유형·최소 크기 조건
- 이름·채팅방 검색, 열 정렬, 채팅방별 접기·펼치기
- 50 MB 이상 파일 보기와 수동 선택
- 중요 표시·개별 항목·채팅방 보호
- 저장 없이 휴지통 이동, 선택한 파일의 PC 다운로드
- 처리 후 남은 목록 유지, 작업 중지와 결과 재확인
- 계정별 보호 목록 백업·복원

## 지원 범위

| 유형 | 조회·선택·휴지통 이동 | PC 저장 |
|---|---|---|
| 사진·GIF·동영상 | 지원 | 지원 |
| 문서·일반 첨부 파일 | 지원 | 지원 |
| 일반 파일로 공유한 음성 파일 | 지원 | 지원 |
| 보이스톡 통화녹음 | 지원 | 미지원 |
| 링크 | 지원 | 미지원 |
| 팀·드라이브 데이터 | 미지원 | 미지원 |

PC 저장의 ‘원본’은 톡클라우드가 제공하는 보관 파일입니다. 카카오톡 전송 과정에서 압축됐다면 촬영 원본과 다를 수 있습니다. 일반 음성 첨부 파일과 보이스톡 통화녹음은 서로 다른 분류입니다.

## 설치

1. [최신 릴리스](https://github.com/git-jiwon/talkcloud-cleaner/releases/latest)에서 실행용 ZIP 또는 소스 코드를 내려받아 계속 보관할 폴더에 압축을 풉니다.
2. Edge 주소창에 `edge://extensions`를 입력하고 **개발자 모드**를 켭니다.
3. **압축 풀린 확장 로드**를 누르고 `manifest.json`이 들어 있는 폴더를 선택합니다.
   - 실행용 ZIP: 압축을 푼 폴더
   - 소스 코드 ZIP 또는 저장소: `extension` 폴더
4. [공식 톡클라우드](https://talkcloud.kakao.com/photo/all)에 직접 로그인하고 필요한 추가 인증을 완료합니다.
5. 톡클라우드 탭에서 **카카오톡 톡클라우드 정리** 확장 아이콘을 누릅니다. 원래 탭도 열어 둡니다.

ZIP이나 `manifest.json` 파일 자체를 선택하지 않습니다. 설치 폴더는 확장이 사용하는 파일이므로 계속 보관해야 합니다.

## 사용

1. **항목 찾기:** 날짜와 유형을 정하고 **목록 찾기**를 누릅니다. 날짜는 한국시간 기준이며 선택한 당일은 제외합니다. 사진·동영상·파일·링크는 올린 날짜, 통화녹음은 녹음 시작일을 사용합니다.
2. **정리할 항목 고르기:** 체크박스로 직접 선택합니다. 기본은 크기 큰 순이며 **50 MB 이상 보기**를 다시 누르면 크기 제한이 풀립니다. 검색·정렬·페이지를 바꿔도 선택은 유지되므로 화면 밖 선택도 확인하세요.
3. **휴지통으로 이동:** 선택 개수·용량을 확인하고 버튼을 누릅니다. 확인 창에서 승인하면 100개씩 처리합니다. 파일 저장은 필수가 아니며 영구 삭제 기능은 제공하지 않습니다.

처리 후 서버에서 결과를 확인하면 남은 목록을 계속 사용할 수 있습니다. 오류·중지로 결과를 확정하지 못하면 목록을 참고용으로 유지하고 추가 작업을 막습니다. **목록 찾기**로 다시 확인하세요.

파일을 보관하려면 **PC에 저장 (선택) → 선택한 파일 …개 저장**을 사용합니다. Edge 다운로드 폴더의 `TalkCloud-Backup` 아래에 저장하며, 완료 후 파일이 잘 열리는지 확인하세요. **다운로드가 끝날 때까지 휴지통 이동 막기**는 필요할 때만 켜는 옵션입니다. 이 확인은 브라우저 다운로드 기록을 기준으로 하며, 파일을 직접 열어 확인하는 과정을 대신하지 않습니다.

자세한 조건과 문제 해결은 확장의 **사용 안내** 또는 [설치 및 사용 안내](extension/guide.html)를 참고하세요. HTML 안내는 내려받은 파일을 브라우저로 열어 읽을 수 있습니다.

## 보호 설정과 업데이트

목록 행의 **보호**로 개별 항목을, **남겨 둘 항목 보호하기 → 채팅방 불러오기**로 채팅방을 보호합니다. 보호 목록은 카카오 계정별로 현재 브라우저 프로필에 저장됩니다. 다른 PC·프로필·새 설치본으로 자동 이동하지 않습니다.

업데이트할 때는 기존 파일을 별도 보관하고 새 실행 파일을 같은 설치 폴더에 반영한 뒤 `edge://extensions`에서 **다시 로드**를 누릅니다. 열린 관리 탭을 닫고 확장 아이콘으로 다시 열어 버전을 확인하세요.

설치 폴더나 프로필을 바꾼다면 기존 관리 화면의 **보호 설정 이전**에서 백업하고 새 설치본에서 **기존 보호 목록과 합쳐 복원**을 실행합니다. 복원 확인 전까지 기존 확장을 제거하지 마세요. 보호 백업은 실제 사진·파일 백업과 다릅니다.

## 개인정보와 권한

로그인은 공식 톡클라우드 탭에서 진행합니다. 확장에는 별도 로그인 입력창, 분석 서비스, 개발자 서버 전송 기능이 없습니다. 정리 요청과 다운로드에는 카카오 서비스 및 파일 제공 호스트와의 통신이 필요합니다.

`activeTab`과 `scripting`은 사용자가 연 톡클라우드 탭에서 기능을 실행하는 데, `downloads`는 선택한 파일 저장과 완료 여부 확인에 사용합니다. 저장 내용, 외부 통신 범위와 공개하면 안 되는 자료는 [개인정보 처리 안내](docs/PRIVACY.md)를 참고하세요.

오류 신고에는 버전·재현 단계·개인정보를 지운 오류 문구만 포함하세요. 계정·파일·채팅방 이름과 식별자, 보호 백업, 목록 JSON, 다운로드 URL 또는 로그인 정보는 공개 이슈에 첨부하지 마세요.

## 제한과 검증 범위

- 공식 공개 API가 아닌 웹 서비스의 내부 요청 방식에 의존합니다. 서비스 변경·로그인·추가 인증·요청 제한에 따라 동작하지 않을 수 있습니다.
- 자동 테스트와 가상 데이터 화면으로 검증했습니다. 실제 계정에서 조회·다운로드·휴지통 이동을 모두 거치는 통합 검증은 완료되지 않았습니다.
- 중요 표시 보호는 통화녹음에 적용하지 않습니다. 통화녹음에는 개별 항목·채팅방 보호를 사용하세요.
- 링크는 용량 합계에서 제외합니다. 크기 미확인 항목과 링크는 검토용 최소 크기 필터에서 제외합니다.
- 용량 합계는 실제 확보 공간과 다를 수 있습니다. 휴지통 보관 기간과 공간 반영은 공식 서비스의 현재 안내를 확인하세요.
- 조회 후 1시간이 지나거나 계정·보호 조건이 달라지면 재조회가 필요합니다.

## 개발 및 테스트

런타임은 빌드 과정 없이 `extension` 폴더에서 실행합니다. 테스트는 Node.js 내장 테스트 러너를 사용하며 별도 패키지 설치가 필요하지 않습니다.

저장소 루트에서 실행합니다.

```powershell
node --test extension/tests/*.test.cjs tools/tests/*.test.cjs
```

공개 파일을 검사하고 설치용·소스 코드 ZIP을 만들려면 다음 명령을 순서대로 실행합니다.

```powershell
node tools/check-public.cjs
node tools/build-public.cjs
```

빌드는 허용 목록의 파일만 `releases`에 담고 기존 같은 버전의 배포본은 덮어쓰지 않습니다. 공개 파일 검사가 모든 개인정보를 자동 판별하는 것은 아니므로 실제 업로드할 내용도 검토해야 합니다. 테스트는 실제 계정 작업을 실행하지 않으며 서비스와의 통합 검증을 대신하지 않습니다.
