# 카카오톡 톡클라우드 정리

<img src="extension/icons/icon128.png" width="64" height="64" alt="노란 구름과 체크 표시 아이콘">

오래된 사진·동영상·파일을 찾아 고르고 휴지통으로 옮기는 **Edge 확장**입니다. PC 저장은 선택입니다.

[**설치용 ZIP 다운로드**](https://github.com/git-jiwon/talkcloud-cleaner/releases/download/v1.0.0/talkcloud-cleaner-v1.0.0.zip) · [변경 사항](docs/RELEASE_NOTES.md)

**1.0.0** · 카카오의 비공식 도구입니다.

## 설치 — 처음 한 번

1. 위 ZIP을 받아 **계속 보관할 폴더**에 압축을 풉니다.
2. Edge에서 `edge://extensions` → **개발자 모드 → 압축 풀린 확장 로드**를 누르고 `manifest.json`이 들어 있는 폴더를 고릅니다.
3. [톡클라우드에 로그인](https://talkcloud.kakao.com/photo/all)하고 **카카오톡 톡클라우드 정리** 확장 아이콘을 누릅니다. 원래 탭도 열어 두세요.

소스 코드 ZIP은 `extension` 폴더를 고릅니다.

## 사용 — 찾기 → 선택 → 휴지통

1. **날짜·유형 → 목록 찾기**. 선택한 날짜 당일은 제외합니다.
2. **썸네일을 확인하고 체크**. 이미지를 누르면 확대됩니다. **50 MB 이상 보기**나 **채팅방별**로 대상을 좁히세요.
3. 개수·용량 확인 후 **휴지통으로 이동**. 보관하려면 먼저 **PC에 저장 (선택)**을 누르세요.

**전체 선택**은 현재 검색·필터 결과를 다른 페이지까지 선택합니다. **현재 페이지 선택**은 보이는 페이지만 선택합니다. 검색·페이지를 바꿔도 체크는 유지되므로 **선택한 항목만 보기**로 확인하세요.

<details>
<summary>미리보기·날짜·지원 유형</summary>

동영상은 대표 이미지만 보이며 GIF는 움직이지 않을 수 있습니다. 원본은 자동 저장하지 않습니다. 이미지가 없으면 **썸네일 칸**을 눌러 다시 확인하세요. 이름 없는 사진은 종류·날짜로 표시합니다.

한국시간 기준으로 올린 날짜를 사용하며, 통화녹음만 녹음 시작일입니다.

| 유형 | 휴지통 이동 | PC 저장 |
|---|---|---|
| 사진·GIF·동영상·일반 파일·음성 첨부 | 지원 | 지원 |
| 보이스톡 통화녹음·링크 | 지원 | 미지원 |
| 팀·드라이브 데이터 | 미지원 | 미지원 |

</details>

<details>
<summary>PC 저장·보호·작업 이어가기</summary>

**PC에 저장 (선택) → 선택한 파일 …개 저장**. Edge 다운로드 폴더의 `TalkCloud-Backup`에 저장합니다. 완료 후 파일을 열어 확인하세요. ‘원본’은 톡클라우드 보관 파일입니다. JSON에는 실제 파일이 없습니다.

보호는 행의 **보호** 또는 **남겨 둘 항목 보호하기 → 채팅방 불러오기**로 설정합니다. 중요 표시 보호는 기본이며 통화녹음에는 적용되지 않습니다. 중요 표시 보호를 켜면 보호 대상만 제외하고 나머지 목록·선택은 유지합니다.

**이전 작업 불러오기**는 최근 7일 이내 기록을 최신 목록으로 확인합니다. 휴지통 이동은 자동 재개하지 않습니다. 작업 기록 지우기는 보호 목록과 PC 파일을 유지합니다.

</details>

<details>
<summary>업데이트·문제 해결·개인정보</summary>

기존 파일을 별도 보관하고 최신 ZIP을 같은 설치 폴더에 반영한 뒤 **다시 로드**합니다. 관리 탭을 새로 열어 목록 위의 **전체 선택** 버튼을 확인하세요. 같은 Edge 프로필·설치본의 보호 설정은 유지됩니다. 폴더·프로필을 바꾼다면 **보호 설정 이전**으로 백업·복원하고 확인 전까지 기존 확장을 유지하세요. 작업 기록은 이전하지 않습니다.

버튼이 꺼져 있으면 화면의 이유를 확인하세요. 연결 오류는 원래 탭에서 로그인·인증을, 중지·결과 미확정은 **목록 찾기**로 다시 확인합니다.

개발자 서버·분석 전송은 없습니다. 작업 기록에 원본·썸네일 URL을 저장하지 않습니다. 오류 신고에는 버전·재현 단계와 개인정보를 지운 오류만 포함하세요.
