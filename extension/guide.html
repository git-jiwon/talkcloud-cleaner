설치 및 사용 안내 1.0.0-rc.2

오래된 항목을 찾고, 고르고, 휴지통으로 옮기세요. PC 저장은 선택입니다.

Edge 설치용 ZIP 다운로드 ↓

처음 설치하기

  1. 위 ZIP을 받아 계속 보관할 폴더에 압축을 풉니다.
  2. Edge에서 edge://extensions를 열고 개발자 모드 → 압축 풀린 확장 로드를 누릅니다. manifest.json이 들어 있는 폴더를 고르세요.
  3. 톡클라우드에 로그인한 뒤 카카오톡 톡클라우드 정리 확장 아이콘을 누릅니다. 원래 탭도 열어 두세요.

세 단계로 정리하기

  1. 날짜·유형을 정하고 목록 찾기를 누릅니다. 선택한 날짜 당일은 제외합니다.
  2. 썸네일을 확인하고 체크합니다. 이미지를 누르면 확대됩니다. 큰 파일은 50 MB 이상 보기로 찾으세요.
  3. 개수·용량을 확인하고 휴지통으로 이동을 누릅니다. 보관할 파일이 있으면 먼저 PC에 저장 (선택)을 사용하세요.

정식 1.0 전 후보 버전입니다. 실제 계정 통합 검증은 아직 완료되지 않았으므로 처음에는 소수의 항목으로 확인하세요.

목록과 미리보기

사진·GIF·동영상은 목록에 썸네일로 표시합니다. 동영상은 대표 이미지만 보이며 재생하지 않습니다. GIF는 움직이지 않을 수 있습니다. 원본은 자동으로 저장하지 않습니다.

이름이 없는 사진은 종류와 날짜로 표시합니다. 이미지가 안 보이면 썸네일 칸을 눌러 다시 확인하세요.

열 제목을 눌러 정렬하고 채팅방별로 묶을 수 있습니다. 검색·페이지를 바꿔도 체크는 유지되므로 선택한 항목만 보기로 전체 선택을 확인하세요.

날짜는 한국시간 기준입니다. 사진·동영상·파일·링크는 올린 날짜, 통화녹음은 녹음 시작일을 사용합니다.

파일을 PC에 저장하기

파일을 체크한 뒤 PC에 저장 (선택) → 선택한 파일 …개 저장을 누릅니다. Edge 다운로드 폴더의 TalkCloud-Backup에 저장합니다. 완료 후 파일을 직접 열어 확인하세요.

저장한 뒤에만 정리하려면 다운로드가 끝날 때까지 휴지통 이동 막기를 켭니다. 기본은 꺼져 있으며, 파일 저장 후 휴지통 이동은 직접 실행합니다.

‘원본’은 톡클라우드에 보관된 파일입니다. 촬영 원본과 다를 수 있습니다. 목록·결과 JSON과 보호 설정 백업에는 실제 파일이 들어 있지 않습니다.

남겨 둘 항목 보호하기

개별 항목은 행의 보호를 누르세요. 채팅방은 남겨 둘 항목 보호하기 → 채팅방 불러오기에서 체크하고 목록 찾기를 다시 누릅니다.

보호는 같은 Edge 프로필·설치본에 계정별로 저장합니다. 해제하려면 같은 보호 목록에서 항목이나 방의 체크를 풉니다. 중요 표시 보호는 기본으로 켜져 있으며 통화녹음에는 적용되지 않습니다.

중단한 작업 이어가기

이전 작업 불러오기를 누르면 최근 7일 이내의 조건·선택·저장 기록을 현재 계정과 최신 목록으로 다시 확인합니다. 휴지통 이동은 자동으로 재개하지 않습니다.

오류나 중지 뒤에는 결과 재확인·남은 항목 선택 또는 목록 찾기로 현재 상태를 확인하세요. 확인된 항목만 목록에서 빠지고 남은 항목은 계속 정리할 수 있습니다.

이 계정의 작업 기록 지우기는 보호 목록과 PC 파일에 영향을 주지 않습니다. 7일은 복원 유효기간이며 저장 데이터의 자동 삭제 기간이 아닙니다.

업데이트·보호 설정 이전

같은 폴더에서 업데이트: 작업을 끝내고 기존 파일을 별도 보관합니다. 새 ZIP을 같은 설치 폴더에 반영한 뒤 edge://extensions에서 다시 로드하세요. 관리 탭을 다시 열어 1.0.0-rc.2를 확인합니다.

폴더나 프로필을 바꾼다면: 기존 확장의 보호 설정 이전에서 백업하고 새 설치본에서 기존 보호 목록과 합쳐 복원하세요. 복원 확인 전에는 기존 확장을 유지합니다. 작업 기록은 이전하지 않습니다.

이 확장의 보호 설정 이전 열기 · 소스 코드 ZIP은 extension 폴더를 설치 대상으로 고릅니다.

버튼이 안 눌리거나 오류가 날 때
  • 휴지통 버튼이 꺼져 있음: 체크한 항목, 진행 중인 작업, 다운로드 완료 조건을 확인하세요.
  • 로그인·연결 오류: 원래 톡클라우드 탭에서 로그인·추가 인증을 끝내고 확장 아이콘을 다시 누르세요.
  • 오래된 목록·결과 미확정: 목록 찾기로 다시 확인하세요. 조회 후 1시간이 지나면 재조회가 필요합니다.
  • 중지: 작업 중지 또는 다운로드 중지를 누르세요. 이미 전달된 요청은 끝날 수 있으므로 결과를 다시 확인합니다.
개인정보·문의

로그인은 공식 톡클라우드에서만 합니다. 개발자 서버나 분석 서비스로 정보를 보내지 않습니다. 작업 기록은 이 Edge에 저장하며 원본·썸네일 URL은 기록하지 않습니다.

오류를 공유할 때는 버전·재현 단계와 개인정보를 지운 오류 문구만 보내세요. 실제 파일·채팅방 이름, 식별자, JSON·보호 백업, 다운로드 주소는 공개하지 마세요.
