EDGE 확장 프로그램

설치 및 사용 안내 0.7.4

찾기 → 선택 → 휴지통 이동. 파일 저장은 필요할 때만 사용합니다.

카카오 공식 프로그램이 아닙니다. 공식 웹페이지의 내부 요청 방식에 의존하므로 서비스 변경에 따라 동작하지 않을 수 있습니다.

자동 테스트와 가상 데이터 화면으로 검증했습니다. 실제 계정의 조회·다운로드·휴지통 이동을 모두 거치는 통합 검증은 완료되지 않았습니다. 처음에는 소수의 항목으로 날짜·유형·보호 조건과 저장 파일을 확인하세요.

처음 설치하기

  1. 배포 ZIP을 내려받아 계속 보관할 폴더에 압축을 풉니다. 실행용 ZIP은 압축을 푼 폴더에, 소스 코드 ZIP은 그 안의 extension 폴더에 manifest.json이 있습니다.
  2. Edge 주소창에 edge://extensions를 입력하고 개발자 모드를 켭니다.
  3. 압축 풀린 확장 로드를 누르고 manifest.json이 들어 있는 폴더를 선택합니다. ZIP이나 JSON 파일 자체를 고르는 것이 아닙니다.
  4. 공식 톡클라우드에서 직접 로그인하고 필요한 추가 인증을 완료합니다.
  5. 톡클라우드 탭을 선택한 상태에서 확장 프로그램 메뉴의 카카오톡 톡클라우드 정리 아이콘을 누릅니다. 원래 톡클라우드 탭과 새 관리 화면을 모두 열어 둡니다.

설치 폴더는 계속 보관하세요. 이 안내 파일을 직접 열 수는 있지만, 정리 기능은 Edge에 설치한 확장 프로그램에서만 실행됩니다.

세 단계로 정리하기

1. 항목 찾기

이 날짜 이전과 찾을 유형을 정하고 목록 찾기를 누릅니다. 최소 크기·나간 채팅방 조건은 조회 조건 더 보기에 있습니다. 보호 대상을 설정하려면 남겨 둘 항목 보호하기를 펼치세요.

기준일이 2021-01-01이면 한국시간 2021년 1월 1일 00:00 이전 항목을 찾습니다. 기준일 당일은 제외합니다. 사진·GIF·동영상·파일·링크는 올린 날짜, 통화녹음은 녹음 시작일 기준이며 사진 촬영일이 아닙니다.

2. 정리할 항목 고르기

조회 직후에는 선택된 항목이 없습니다. 목록의 왼쪽 체크박스로 정리할 항목을 고르세요. 기본 정렬은 크기 큰 순입니다.

  • 이름 또는 채팅방 검색, 열 제목 정렬, 채팅방별 보기로 목록을 살펴봅니다.
  • 50 MB 이상 보기는 큰 파일을 크기순으로 보여 줍니다. 다시 누르면 크기 제한이 풀립니다. 자동으로 항목을 선택하지 않습니다.
  • 지금 보이는 …개 선택은 보이는 페이지를 선택합니다. 다른 페이지를 포함하려면 필터·정렬 더 보기 → 검색 결과 전체 …개 선택을 사용합니다.
  • 검색·정렬·페이지·채팅방 접기를 바꿔도 선택은 유지됩니다. 화면 밖의 선택 안내를 확인하고, 선택한 항목만 보기로 선택 전체를 검토할 수 있습니다.
  • 계속 남겨 둘 항목은 행의 보호를 누릅니다. 현재 목록에서 제외하고 다음 조회에도 보호합니다.

3. 휴지통으로 이동

선택 개수와 용량을 확인하고 휴지통으로 이동을 누릅니다. 확인 창에서 실행을 승인하면 선택한 항목을 100개씩 순서대로 처리합니다. PC에 파일을 저장하지 않아도 정리할 수 있습니다. 개수를 다시 입력하거나 1,000개마다 버튼을 누를 필요는 없습니다.

처리 결과를 재조회해 확인하면 처리된 항목만 빠지고 남은 목록을 계속 정리할 수 있습니다. 검색·정렬·채팅방 펼침은 유지하고 선택은 해제합니다. 오류나 중지로 결과를 확정하지 못하면 기존 목록을 참고용으로 남기고 추가 작업을 막습니다. 이때는 목록 찾기로 다시 확인하세요.

이 확장은 영구 삭제 기능을 제공하지 않습니다. 휴지통 보관 기간, 복구 가능 여부와 공간 반영은 공식 휴지통의 현재 안내를 확인하세요. 목록의 용량 합계가 실제 확보 공간과 같다고 보장하지 않습니다.

필요한 파일만 PC에 저장하기

파일을 선택하고 PC에 저장 (선택)을 누르면 다운로드 도구가 열립니다. 선택한 파일 …개 저장을 눌러 실제 저장을 시작하세요. 저장이 끝나도 자동으로 휴지통에 옮기지 않습니다.

유형PC 저장
사진·GIF·동영상지원합니다. 톡클라우드가 제공하는 보관 파일을 저장합니다.
문서·일반 첨부 파일지원합니다. 일반 파일로 공유한 음성 파일도 포함합니다.
보이스톡 통화녹음이 확장의 다운로드 기능은 지원하지 않습니다. 일반 음성 첨부 파일과 다른 분류입니다.
링크다운로드하지 않습니다. 연결된 웹페이지나 그 안의 파일도 저장하지 않습니다.
저장 위치
Edge 다운로드 폴더의 TalkCloud-Backup 아래 실행별 폴더에 저장합니다. 같은 이름은 새 이름을 붙여 보존합니다. 브라우저가 저장 위치를 물으면 해당 안내에 따라 진행하세요.
‘원본 저장’의 의미
톡클라우드에 보관된 파일입니다. 카카오톡 전송 과정에서 압축됐다면 촬영 원본과 다를 수 있습니다. Edge가 완료한 다운로드만 완료로 표시하며, 파일이 잘 열리는지는 직접 확인하세요.
저장 완료를 확인한 뒤에만 정리하려면
다운로드가 끝날 때까지 휴지통 이동 막기를 켭니다. 기본은 꺼져 있습니다. 이 옵션은 사진·GIF·동영상·일반 파일에만 적용하며 링크·통화녹음에는 적용하지 않습니다.
이미 백업했는데 저장을 요구한다면
현재 관리 화면에서 확인한 다운로드 기록을 사용합니다. 이전 관리 탭이나 다른 프로그램에서 저장한 파일은 자동 인정하지 않습니다. 이미 보관한 파일을 확인했다면 저장 확인 옵션을 끄고 정리할 수 있습니다.
JSON 기록과 실제 파일의 차이
목록 정보 저장 (.json)은 선택 항목의 메타데이터를, 다운로드 결과 기록 (.json)은 저장 내역을 기록합니다. 보호 설정 백업 JSON은 보호 목록을 담습니다. 어느 JSON에도 사진·동영상·문서 내용 자체는 포함되지 않습니다.

남겨 둘 항목 보호하기

개별 항목
조회 행의 보호를 누르면 이후 조회에서도 제외합니다. 보호를 풀려면 남겨 둘 항목 보호하기 → 개별 항목 보호에서 해당 항목을 해제합니다. 전체 보호 해제는 개별 항목 보호 목록을 비웁니다.
채팅방 전체
남겨 둘 항목 보호하기 → 채팅방 불러오기 → 이름 검색 → 보호할 방 체크 → 목록 찾기 순서로 사용합니다. 선택한 방은 모든 지원 분류에서 보호합니다. 보호 채팅방이 있을 때 방 정보를 확인할 수 없는 항목도 대상에서 제외합니다.
나간 채팅방
나간 채팅방은 한 묶음으로 표시됩니다. 이 묶음을 보호하면 나간 채팅방 전체를 보호합니다.
중요 표시 항목
중요 표시 항목 보호는 기본으로 켜져 있습니다. 사진·GIF·동영상·파일·링크의 중요 표시가 있거나 여부가 불명확한 항목을 제외합니다. 통화녹음에는 이 옵션을 적용하지 않으므로 개별 항목·채팅방 보호를 사용하세요.
저장 범위
보호 목록은 카카오 계정별로 현재 Edge 프로필의 확장 로컬 저장소에 보관합니다. 다른 PC·프로필·새 설치본으로 자동 이동하지 않습니다. 확장 제거 또는 데이터 초기화 전에 필요한 보호 목록을 백업하세요.

분류별 차이

  • 사진·GIF·동영상·파일: 날짜, 최소 파일 크기, 중요 표시, 개별 항목·채팅방 보호 조건을 적용합니다.
  • 링크: 날짜와 보호 조건을 적용합니다. 용량 합계에서 제외하고 1단계의 최소 파일 크기는 적용하지 않습니다.
  • 통화녹음: 녹음 시작일, 최소 파일 크기, 개별 항목·채팅방 보호 조건을 적용합니다. ‘나간 채팅방 포함’과 관계없이 전체 범위를 조회합니다.
  • 팀·드라이브 데이터: 이 확장의 조회·저장·정리 대상에 포함하지 않습니다. 공식 서비스에서 관리하세요.

2단계의 검토용 크기 필터는 링크와 크기 미확인 항목을 제외합니다. 크기 정렬에서는 이 항목들을 뒤에 표시합니다. 1단계 조건을 바꾸면 재조회가 필요하고, 2단계 필터는 이미 조회한 목록에만 적용합니다.

업데이트와 보호 설정 이전

같은 설치 폴더에서 업데이트

  1. 기존 파일을 별도 보관하고 새 버전의 실행 파일을 같은 설치 폴더에 반영합니다. 보호 목록은 미리 백업할 수 있습니다.
  2. edge://extensions에서 이 확장의 다시 로드를 누릅니다. 새 권한 안내가 나오면 용도를 확인합니다.
  3. 열려 있던 관리 탭을 닫고 공식 톡클라우드 탭에서 확장 아이콘을 다시 누릅니다. 화면의 버전이 0.7.4인지 확인합니다.

설치 폴더·브라우저 프로필을 바꾸는 경우

  1. 다른 관리 탭을 닫고 기존 확장 관리 화면 → 보호 설정 이전 → 보호 설정 백업 만들기 → 백업 파일 저장을 진행합니다.
  2. 새 설치본을 등록하고 그 관리 화면의 보호 설정 이전에서 백업 파일을 선택합니다.
  3. 항목 수를 확인하고 기존 보호 목록과 합쳐 복원을 누릅니다. 새 설치본의 보호 항목도 유지합니다.
  4. 저장 후 보호 목록 확인 완료를 확인한 뒤 관리 화면을 다시 열어 보호 목록을 확인합니다. 확인 전까지 기존 확장은 제거하지 마세요.

현재 확장의 보호 설정 이전 화면 열기

파일 주소로 연 페이지에서는 확장 설정을 읽을 수 없습니다. 위 이전 도구는 설치된 확장 안에서 여세요. 보호 설정 백업에는 계정·항목 식별자와 이름이 들어 있으므로 비공개로 보관하세요. 조회 조건의 체크박스는 새 관리 화면에서 다시 확인합니다.

문제가 생겼을 때

조회·휴지통 이동 중지
선택 요약 옆의 작업 중지를 누릅니다. 이미 전달된 요청은 끝날 수 있습니다. 일부가 처리됐을 수 있으므로 목록 찾기로 다시 확인하세요.
다운로드 중지
다운로드 중지를 누릅니다. 이미 완료된 PC 파일은 남습니다. 미완료 항목은 저장 완료로 계산하지 않습니다.
결과 미확정 또는 참고용 목록
서버 결과를 확정하지 못한 상태입니다. 기존 목록은 남지만 추가 휴지통 이동과 다운로드를 막습니다. 공식 톡클라우드와 휴지통을 확인한 뒤 재조회하세요. 미확정 작업을 자동 재실행하지 않습니다.
파일 유형 정보가 맞지 않는 항목
유형 정보가 서로 맞지 않는 미디어 항목은 제외하고 조회를 계속합니다. 제외 개수를 확인하세요. 식별자·날짜·계정 정보의 이상은 작업 중단 사유입니다.
휴지통 이동 버튼이 비활성 상태
선택한 항목이 없거나 다른 작업이 진행 중일 수 있습니다. 저장 확인 옵션을 켰다면 미완료 다운로드도 원인입니다. 선택 요약의 안내를 확인하세요.
로그인·연결 오류 또는 오래된 조회
원래 톡클라우드 탭에서 로그인·추가 인증을 완료하고, 필요하면 새로고침 후 확장 아이콘으로 관리 화면을 다시 여세요. 조회 후 1시간이 지난 목록은 다시 조회해야 합니다.
오류를 신고할 때
버전, 수행한 단계, 개인정보를 지운 오류 문구를 알려 주세요. 계정·채팅방·파일 이름이나 식별자, 보호 백업, 목록 JSON, 다운로드 URL, 로그인 정보를 공개 이슈에 첨부하지 마세요. 화면 캡처도 해당 정보를 먼저 가려 주세요.

이 안내는 확장에 포함된 로컬 문서입니다. 외부 글꼴·이미지·스크립트를 불러오지 않습니다.
